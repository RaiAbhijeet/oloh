2. Allgemeines zur Datenverarbeitung

Wir nehmen den Schutz Ihrer personenbezogenen Daten sehr ernst. Diese Website ist eine rein statische Website ohne Datenbanken, Login-Bereiche oder Kontaktformulare. Es werden keine personenbezogenen Daten aktiv durch uns erfasst oder gespeichert.

Allerdings werden durch die genutzten Drittdienste (Hosting, CDN, Schriftarten) technische Daten übermittelt, die nach DSGVO erläutert werden müssen. Die folgende Datenschutzerklärung klärt Sie über Art, Umfang und Zweck der Verarbeitung auf.

Rechtsgrundlage für die Datenverarbeitung ist Art. 6 Abs. 1 lit. f DSGVO (berechtigte Interessen — Bereitstellung und Sicherheit der Website).

3. Hosting: GitHub Pages

Diese Website wird auf den Servern von GitHub Pages gehostet, einem Dienst von:

GitHub, Inc.
88 Colin P Kelly Jr Street
San Francisco, CA 94107, USA

Beim Aufruf der Website übermittelt Ihr Browser automatisch Daten an die Server von GitHub, insbesondere:

  • IP-Adresse des anfragenden Geräts
  • Datum und Uhrzeit des Zugriffs
  • Aufgerufene Seite (URL)
  • Browsertyp und Betriebssystem
  • Referrer-URL (zuvor besuchte Seite)

Diese Daten werden von GitHub zur Sicherstellung des Betriebs und der Sicherheit des Dienstes verarbeitet. GitHub kann diese Daten in die USA übertragen. GitHub Inc. ist nach dem EU-US Data Privacy Framework (DPF) zertifiziert, was eine angemessene Schutzgarantie für Datentransfers in die USA darstellt.

Weitere Informationen: GitHub Datenschutzerklärung

Cloudflare, Inc.

San Francisco, CA 94107, USA

Beim Besuch unserer Website werden Anfragen über das weltweite Netzwerk von Cloudflare geleitet. Dabei können folgende Daten verarbeitet werden:

Cloudflare ist nach dem EU-US Data Privacy Framework (DPF) zertifiziert. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse: Sicherheit und Verfügbarkeit der Website).

6. Cookies und lokaler Speicher

Wir selbst setzen keine Tracking- oder Marketing-Cookies. Diese Website speichert lediglich Ihre Sprachpräferenz (Deutsch / Englisch) im localStorage Ihres Browsers, damit Sie beim nächsten Besuch dieselbe Sprache sehen. Dieser Eintrag:

  • enthält keine personenbezogenen Daten
  • wird nicht an unsere Server oder Dritte übertragen
  • bleibt ausschließlich auf Ihrem Gerät
  • kann jederzeit im Browser unter „Webseitendaten löschen" entfernt werden
